# Shot % — จับเปอร์เซ็นต์ชู้ตด้วยกล้อง

แอปเดียว งานเดียว: **นับเข้า/พลาด แล้วบอกเปอร์เซ็นต์ให้ตรงที่สุด**

วิธีทำงาน: กล้องจับลูกบอลด้วยสี แล้วดูว่าลูกผ่านกรอบห่วงลงมาในแนวดิ่งหรือเด้งออก
ระบบตัดสินให้เองทุกลูก และ **ทุกลูกแตะแก้ได้ 1 ครั้ง** — นี่คือจุดที่ตัวเลขสุดท้ายแม่นกว่าระบบที่ตัดสินเองแล้วแก้ไม่ได้

---

## ใช้ครั้งแรก 4 ขั้น

1. **เปิดกล้อง** — ต้องเปิดหน้านี้ผ่าน https หรือ localhost (ดูหัวข้อการติดตั้งด้านล่าง)
2. **แตะลูกบอล** — กดปุ่มแล้วแตะกลางลูกบอลในภาพ แอปจะจำสีลูกจากลูกจริงของคุณ ไม่ใช่สีส้มมาตรฐาน
3. **แตะห่วง** — แตะกลางห่วง จะเห็นกรอบเหลือง (ห่วง) และกรอบเขียวประ (โซนใต้ห่วง)
4. **เริ่มจับอัตโนมัติ** — ยิงได้เลย

ตัวเลข “จุดที่ตรงสี” มุมซ้ายบนคือเครื่องมือจูน: ตอนไม่มีลูกในกรอบควรใกล้ 0 ตอนลูกเข้ากรอบควรพุ่งขึ้น
ถ้าไม่เป็นแบบนั้น เปิด **ตั้งค่าละเอียด** แล้วขยับ “ความไวการจับสี”

---

## วางกล้องอย่างไรให้แม่น

ความแม่นของระบบแบบนี้มาจากการวางกล้อง มากกว่ามาจากโค้ด

- **ตั้งมือถือด้านข้างห่วง เยื้องออกไปประมาณ 3–4 เมตร ให้เห็นห่วงชัดและใหญ่** ห่วงควรกินพื้นที่จอพอสมควร ยิ่งห่วงเล็กในภาพ ยิ่งพลาด
- **ห้ามถือมือถือ** ใช้ขาตั้งหรือพาดกับกระเป๋า ถ้าภาพขยับ กรอบห่วงจะเลื่อนและตัดสินผิดทันที
- **หลังห่วงควรเป็นสีที่ต่างจากลูกบอล** ถ้าฉากหลังเป็นอิฐสีส้มหรือดินลูกรัง ระบบจะสับสน ให้เปลี่ยนมุมกล้องให้ฉากหลังเป็นท้องฟ้าหรือกำแพงสีเรียบ
- **แสงสม่ำเสมอ** ตอนเช้าหรือเย็นที่แดดไม่แข็งดีที่สุด กลางแดดจัดลูกจะสว่างจนสีเพี้ยน ให้แตะจับสีลูกใหม่เมื่อแสงเปลี่ยน
- **ยิงทีละลูก เว้นจังหวะราว 1 วินาที** ระบบล็อกไม่ให้นับซ้ำใน 1.1 วินาที ถ้ายิงรัวจะนับไม่ครบ

หลังยิงเสร็จ 10 ลูก ให้ไล่ดูชิปด้านล่างว่าตรงกับที่จำได้ไหม แตะแก้ลูกที่ผิด แล้วกดจบเซสชัน

---

## เรื่องความแม่น พูดกันตรง ๆ

การตรวจจับด้วยสีอย่างนี้ทำได้ราว 70–90% ในสภาพที่วางกล้องดี แต่จะแย่ลงทันทีเมื่อฉากหลังสีใกล้ลูกบอล
Ball.ai ใช้โมเดลตรวจจับวัตถุที่เทรนจากคลิปจำนวนมาก จึงทนสภาพแวดล้อมได้ดีกว่าในส่วนของการ “มองเห็น”

สิ่งที่แอปนี้ทำได้ดีกว่า คือ **ตัวเลขสุดท้าย** เพราะทุกลูกมีชิปให้ตรวจและแก้ได้ทันทีในหนึ่งแตะ
ระบบที่ตัดสินเองแล้วแก้ไม่ได้ ถ้าพลาด 3 ลูกจาก 50 เปอร์เซ็นต์ก็เพี้ยนไป 6 จุดโดยไม่มีใครรู้

ถ้าจะให้การ “มองเห็น” แม่นระดับนั้นจริง ต้องขยับไปเขียนแอปเนทีฟด้วย Swift + Core ML บน Xcode
โดยเทรนโมเดลจากคลิปสนามที่ตัวเองซ้อมจริง — แอปนี้ช่วยเก็บข้อมูลตั้งต้นให้ได้ก่อน

## ติดตั้งให้เป็นแอปบนไอโฟน

กล้องบนเว็บเปิดได้เฉพาะผ่าน https หรือ localhost เท่านั้น

**ทดสอบบน MacBook (2 นาที)** เปิด Terminal ที่โฟลเดอร์นี้:

```bash
python3 -m http.server 8000
```

แล้วเปิด `http://localhost:8000` ใน Chrome

**ใช้จริงบนไอโฟน (ฟรี, 10 นาที)**

1. สร้าง repository ใหม่บน GitHub ตั้งเป็น Public
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
3. Settings → Pages → Source: `Deploy from a branch` → branch `main`, folder `/ (root)` → Save
4. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`
5. เปิดลิงก์ใน **Safari** บนไอโฟน → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**

เปิดจากไอคอนบนหน้าจอโฮมจะเต็มจอเหมือนแอปทั่วไป และใช้ได้แม้ไม่มีสัญญาณ
